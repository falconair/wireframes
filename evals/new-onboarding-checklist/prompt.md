New users of our project-management web app land on an empty dashboard and most never create
a second project. We want a "Get started" checklist on the dashboard for the first week:
create a project, invite a teammate, add a task with a due date, connect Slack. It should be
dismissible and show progress. Nothing like this exists yet. Show me what you have in mind
before anyone builds it.
