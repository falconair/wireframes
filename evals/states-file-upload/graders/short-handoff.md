The final chat message is a short handoff, not a write-up. It links or names the mockup HTML file in a mockups/ folder, lists each proposed change in about one line, and states any decision the user must make with a recommendation. It does NOT re-describe in prose what the drawings show (no long paragraphs per change, no restated layouts), does not paste HTML, and asks the user to look and decide before anything is built.
