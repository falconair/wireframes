# Privacy

wireframes is a set of instructions (`SKILL.md`) and a stylesheet (`kit.html`) for coding
agents. It has no server, no account and no analytics.

- **It collects nothing.** The skill doesn't read personal data and doesn't ask the agent to.
- **It sends nothing.** The skill makes no network requests and doesn't ask the agent to send
  anything anywhere.
- **It stores one file.** When the skill is used, the agent writes one HTML file into your
  project, in `docs/mockups/` or your existing mockups folder. It stays on your machine
  unless you commit and push it yourself.

The agent you run the skill in (Claude Code, Codex, Copilot and so on) has its own privacy
policy, which covers what that agent does with your prompts and files.

Questions: open an issue at https://github.com/falconair/wireframes/issues.
